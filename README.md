# IT00CH95-3004 Data Science  
**Data Science Course Repository – Åbo Akademi University**  

Welcome to the repository for the **Data Science** course (IT00CH95-3004) at Åbo Akademi University. This repository contains all the practical work completed during the course, including **labs** and **mini projects**.  

## 📂 Repository Structure  
The repository is organized into two main directories:  

### 1. **LABS**  
Contains three subfolders for each lab assignment. Each folder includes:  
- **Lab Manual** – Detailed instructions and objectives of the lab.  
- **Jupyter Notebook** – Solution file for the lab tasks.  

**Exception:**  
- **LAB 3** – Instead of a typical lab, this task involved replicating a research paper. The folder includes:  
  - The research paper (if applicable) or reference.  
  - A detailed report on the replication process and results.  

### 2. **MiniProjects**  
Contains three subfolders for each mini project. Each folder includes:  
- **Project Requirements** – Document outlining the project objectives and tasks.  
- **Jupyter Notebook** – The solution and implementation for the project.  
- **Project Report** – A comprehensive report detailing the project process, analysis, and results.  

## 📁 Navigation Guide  
- To explore lab work, navigate to the **LABS** folder and open the relevant subfolder (Lab 1, Lab 2, or Lab 3).  
- For mini projects, visit the **MiniProjects** directory and select the desired project folder. Each project folder is self-contained, with all necessary documentation and solutions.  

## 🔧 Tools and Technologies  
- **Python**  
- **Jupyter Notebooks**  
- Various data science libraries (Pandas, NumPy, Matplotlib, Scikit-learn, etc.)
